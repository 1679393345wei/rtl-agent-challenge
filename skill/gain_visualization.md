# 增益可视化（gain_visualization）

> 数据来源：服务器 `results/baseline_v12.csv` 与 `results/agent_verified_v12.csv`

## 总体增益

| 指标 | 基线 | Agent | 增益 |
|---|---|---|---|
| pass@1 | 51.92%（81/156） | 58.33%（91/156） | **+6.41 个百分点（+10 题）** |

## 分项增益（旧分类口径 73/38/37/8）

| 类别 | 基线 | Agent | 变化 |
|---|---|---|---|
| 时序 sequential | 36.84% | 63.16% | **+26.32 ↑** |
| 综合 complex | 12.50% | 25.00% | +12.50 ↑ |
| 组合 combinational | 73.97% | 79.45% | +5.48 ↑ |
| FSM fsm | 32.43% | 18.92% | **-13.51 ↓** |

## 逐题翻转（Flipping）

- **提升题（基线挂 → Agent 过）：24 题**，分布：sequential 12、combinational 8、complex 2、fsm 2
- **倒退题（基线过 → Agent 挂）：14 题**，分布：fsm 7、combinational 4、sequential 2、complex 1
- 净增：24 - 14 = **+10 题**

### FSM 倒退题（重点复看）
Prob079、Prob121、Prob127、Prob135、Prob136、Prob138、Prob148（全是 pass → sim_fail）

## 失败类型变化

| 状态 | 基线 | Agent |
|---|---|---|
| pass | 81 | 91 |
| sim_fail | 65 | 62 |
| compile_fail | 7 | 3 |

> Agent 主要降低了 compile_fail（7→3），但 sim_fail 几乎没变（65→62），说明 Agent 修的是"语法/编译"层，对"行为逻辑错误"改善有限。

## 提示词消融实验（prompt_B 系列 pass@1）

| 版本 | pass@1 | FSM 分项 |
|---|---|---|
| baseline（A 组） | 51.92% | 32.43% |
| B_v2 | 44.23% | 10.81% |
| B_v3 | 46.15% | 21.62% |
| B_v5 | 48.08% | 21.62% |
| B_v6 | 51.28% | 31.03% |
| B_v7 | 55.77% | 20.69% |
| B_v8 | **58.97%（峰值）** | **41.38%（FSM 峰值）** |
| B_v9 | 58.33% | 31.03% |
| B_v10 | 56.41% | 20.69% |
| B_v11 | 54.49% | 17.24% |
| B_v12 | 48.72% | 24.32% |

> 结论：B_v8 之后总分和 FSM 分项双双回落，v8 之后的模板改动 + 降温度是负优化。

## 稳定性实验（同模板连跑 3 次）

56.41% / 57.69% / 58.97%（均值约 57.7%，极差约 2.5 个点），说明存在随机波动。
