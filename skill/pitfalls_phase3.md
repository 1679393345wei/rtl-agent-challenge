# 阶段3 踩坑记录（提示词工程）

> 记录提示词调试经验：什么样的约束风格有效、什么样的无效。
> 对应方案阶段3：提示词工程（分类 + 模板 + 消融实验）。
> 消融实验的完整数据见 `prompts_cookbook.md` 与 `gain_visualization.md`。

## 有效的做法（正向经验）

### insight-01: 明确「禁用 always_ff / always_comb / always_latch」收益巨大

这在阶段0已经验证（改后编译失败从约 70 题降到 8 题），在提示词优化阶段依然是所有模板的**保留项**。任何一版删掉这条都会立刻多出一批 `compile_fail`。

### insight-02: `case` 必须带 `default` 分支（FSM/综合）

FSM 模板强制 `case` 带 `default`，有效避免了「状态未覆盖时生成锁存器/未知态」导致的行为错误。这是 FSM 类模板的基础约束。

### insight-03: ~~更严格的 FSM 约束能显著压住行为错误（B_v8 关键结论）~~ **【2026-10-08 已推翻】**

`prompts_b8/system_fsm.txt` 比当前多两条规则：
- `禁 case ... inside / casez 复杂模式，只用简单 case`
- `声明所有端口，禁止未声明信号`

B_v8 在 B 系列消融内拿到 **FSM 分项峰值 41.38%**；删掉这两条后（B_v9 起）FSM 跌到 17%~24%。

> **⚠️ 修正**：C 侧独立对照实验（29 道 FSM 题、统一口径、同温度）显示：**不加专用提示词的对照通过率 ~41%，高于所有 FSM 专用提示词版本**（B_v8 恢复版 31.0%、精简版 17.2%、增强版 ~17%），且**规则越多越差**。A 侧交接总结亦记录「FSM few-shot 无稳定收益」。
>
> 因此原结论「约束越具体越有效」**不成立**——B_v8 的 41.38% 只是同批消融内的相对最优，不能推出「专用提示词优于无提示词」。详见 `prompts_cookbook.md` 第六节。

### insight-04: 纯组合 FSM 题需要单独追加提示

8 道「纯组合 FSM」题（079/091/099/100/134/135/143/150）看起来像状态机，实则是纯组合逻辑。若不加提示，模型会习惯性加时钟和状态寄存器，直接违背题意（见 `report/fsm_failure_analysis.md` 的 Prob135 案例）。在评测脚本里对这 8 题追加「这是组合 FSM，勿加时钟/复位」后，此类错误明显减少。

## 无效 / 负优化的做法（反向经验）

### insight-05: ~~删除 B_v8 的两条 FSM 规则是负优化~~ **【2026-10-08 已推翻】**

B_v8 → B_v9 仅删了「禁复杂 case」和「声明所有端口」两条，pass@1 从 58.97% 掉到 58.33%，FSM 分项从 41.38% 掉到 31.03%。

> **⚠️ 修正**：该对比发生在**同批消融内部**，缺少「无专用提示词」的对照。C 侧独立复测补齐对照后，结论反转（见 insight-03）。**不应再据此恢复这两条规则。**

### insight-06: temperature=0.2 是负优化

B_v11 把温度降到 0.2，pass@1 反而从 56.41% 掉到 54.49%（FSM 仅 17.24%）。温度过低导致生成多样性不足、答案趋于单一，对部分题的写法反而更差。

### insight-07: 误导性的 reset 规则要删

B_v6 → B_v7 删除了模板里一条「误导性的 reset 规则」后，pass@1 从 51.28% 升到 55.77%。规则若与题目实际复位语义（同步/异步）冲突，反而会引入错误。

## 经验总结（2026-10-08 修订）

1. **约束要具体到"禁止什么"，而不是泛泛说"怎么写"**：`禁 always_ff`、`声明所有端口` 这类具体禁令确实比空话有效——但**仅限语法层**（compile_fail 类）。对行为层（sim_fail 类），加规则不一定有用。
2. ~~**严格约束对 FSM 类最划算**~~ → **FSM 专用提示词整体是负收益**：独立对照实验显示不加专用提示词反而更好（~41% vs 17%~31%），且规则越多越差。FSM 的增益应交给确定性解析，而不是堆提示词规则。
3. **温度不是越低越好**：0.6 太飘、0.2 太死，0.3 是当前经验上的平衡点。
4. **分类要准**：8 道纯组合 FSM 题若分错类，会套错模板、加错时钟，是系统性错误的来源。
5. **对照口径决定结论**：「同批消融内的相对最优」不等于「优于基线」。任何提示词结论都必须包含**无提示词对照**才能成立——这是本项目最贵的一课。
